ブラウザ内 日本語TTS (ONNX Runtime Web)

g2p (OpenJTalk系/WASM) → encoder → vocoder がすべてこのページ内で動きます。サーバー送信なし。 モデルは選択時に読み込み (0.8〜5.9MB)。自由入力の g2p 辞書 (WASM) は初回のみ ~60MB (ブラウザにキャッシュされます)。

encoder は variance+PostNet+GAN の完成形 (fp32-slim ONNX)。 g2p は piper-plus の WASM phonemizer (NAIST-JDIC 同梱, MIT)。学習時の pyopenjtalk とアクセント句推定が僅かに異なる文があります (音素体系は同一・破綻はしません)。 ← 評価ページ ｜ ソース
